# Separate Shared Agent governance from Local Custody

A Shared Agent's identity, lifecycle, shared permissions, and task eligibility are governed by its Workspace, while the member hosting its Runtime retains authority over the host Device, private context, credentials, and whether that Device continues to execute. Runtime placement is an execution binding rather than ownership of the Agent, so a Host may restrict or stop local execution but cannot unilaterally redefine the Shared Agent's identity or Workspace authority.
