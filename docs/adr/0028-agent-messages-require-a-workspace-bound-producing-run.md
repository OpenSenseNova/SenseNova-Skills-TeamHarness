# Persistent Agent Messages use Binding and receipt provenance

Persistent Agent Session chat Messages are not Run/Attempt results. Workspace binds the author, membership-at-time, Computer, active Runtime Binding revision, target and claim receipt from trusted authority at commit time; Runtime cannot self-report these fields or the Discussion frontier. An explicit task execution may separately record producing Run/Attempt provenance, but that path is not required or synthesized for persistent chat. Human-authored Messages have no execution provenance.
