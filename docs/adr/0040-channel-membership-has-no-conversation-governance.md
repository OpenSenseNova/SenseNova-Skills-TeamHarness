# Channel membership has no Conversation-local governance

Any active Human Workspace Member may create a Workspace Channel, and any active Human Project Member may create a Channel in that Project. Creation fixes the scope but creates no participant records. Current scope Membership alone determines discovery, history access, publication, structured Agent mention eligibility, and the read-only participant projection.

There is no add/remove participant API, Channel owner recovery, or management-role bypass. Membership is governed only through Workspace and Project membership commands. Agent execution never gains scope membership governance, and DM remains undiscoverable outside its two fixed direct participants.
