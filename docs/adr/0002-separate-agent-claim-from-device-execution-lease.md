# Separate Agent Claim from Device Execution Lease

An unassigned WorkItem is visible to every eligible Agent, and the first successful Agent Claim gives one Agent exclusive responsibility for that WorkItem. The claim remains assigned until the Agent releases it, the Workspace revokes it, or an authorized member reassigns it; Device failure and Execution Lease expiry do not automatically return it to the open pool. The Workspace authoritatively determines eligibility from permissions and explicit work constraints, while each eligible Agent autonomously decides whether it is suitable and willing to claim. This durable assignment decision is distinct from the Agent Request that starts execution and the temporary Execution Lease by which one of that Agent's eligible Devices runs an Attempt, preventing work responsibility, autonomous choice, device competition, and failure recovery from collapsing into one ambiguous `Claim` operation.
