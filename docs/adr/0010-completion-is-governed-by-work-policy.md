# Completion is governed by Work Policy

A Run ends from an execution-layer terminal outcome and never completes a WorkItem by publishing a Message. An explicitly managed WorkItem uses a current versioned Completion Policy: manual Human completion, automatic completion from the Result Submission referenced in its sole Current Submission role, or completion gated by an accepted independent Review of that Submission. Policy changes apply immediately to the non-terminal WorkItem rather than binding old policy to each Submission, and completion records the policy revision used. Current Submission is a WorkItem relationship, not another object or Submission state; a newer immutable Submission atomically replaces the reference. Review remains a separate lifecycle, and rejection creates no Run unless its feedback Message explicitly requests an Agent.
