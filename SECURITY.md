# Security policy

This project is an early self-hosted MVP. Do not use it for production or
sensitive data without adding an external identity provider, secret rotation,
backups, monitoring, and a threat-model review appropriate for your deployment.

Please do not disclose vulnerabilities in a public issue. Use a private GitHub
security advisory for this repository, or contact the repository maintainers
with a minimal reproduction, affected commit, and impact. Never include real
passwords, bearer tokens, join-link tokens, database files, or private agent
output in a report.
